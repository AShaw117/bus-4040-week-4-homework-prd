# Client Discovery Questions

## Priority - ask these first

Question 1: When you look up a past event, what is the piece of info that is most
important/most relevant? What are you trying to accomplish by sorting through past
events?

Question 2: If there have been no-shows or repeat speakers, how would you like that to
be dealt with? No shows not shown up unless specified? Repeat speakers grouped as one?

Question 3: Beyond speakers, topics, and time blocks - what else does a schedule
actually need to include to be usable (meals, breaks, sponsor/logistics info, recurring
boilerplate, venue details, etc.)?

## Backup - if time allows

Question 4: What part of the process causes the most friction/frustration? What part is
"most enjoyable"?

Question 5: Who else besides the program coordinator touches or uses these schedules
(assistants, speakers' office, marketing, etc.)?

Question 6: Roughly how many files/events total across 2016-2026, and do they have all
of them digitized, or are some paper/lost?

Question 7: When building a new schedule today, do they usually start from the most
recent one, or from whichever past program's structure is closest to what they need?

Question 8: When building a new schedule, do they want to start from scratch each time,
or from a standardized fill-in-the-blank template based on past events?

Question 9: Between the database (organized historical data) and the schedule builder,
which matters more to them if we had to prioritize?

Question 10: For "analysis" - what specifically do they want to analyze? (e.g., time
spent per session/topic, session runtimes, speaker frequency, program length trends,
attendee engagement)
